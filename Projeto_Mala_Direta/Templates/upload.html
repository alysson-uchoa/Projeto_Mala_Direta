Perguntas Frequentes (FAQ)
Tire suas dúvidas sobre o envio de mala direta
Como enviar uma mala direta?

1. Selecione um arquivo Excel/CSV com os dados
2. Escolha a folha correta (se houver múltiplas)
3. Marque as colunas que deseja incluir no e-mail
4. Preencha o nome da coluna do e-mail e do destinatário
5. Escolha a origem dos dados (arquivo, dataframe, ambos ou nenhum)
6. Digite o assunto e o corpo do e-mail
7. Clique em "Enviar"

O que é o {dataframe}?

O {dataframe} é uma variável especial que, quando inserida no corpo do e-mail, será substituída automaticamente por uma tabela HTML contendo os dados do destinatário (apenas as colunas que você selecionou). Esta tabela aparecerá formatada com as cores do sistema. O {dataframe} só aparece no editor quando você seleciona "Usar DataFrame do arquivo" ou "Ambos" como origem dos dados.

O que são {sum[coluna]} e {sum[col1]/sum[col2]}?

São expressões de cálculo automático que você pode usar no corpo do e-mail. O sistema (pandas) irá calcular e substituir pelos valores reais do seu DataFrame.

Exemplos:

  • {sum[Valor]} → Soma todos os valores da coluna "Valor"
  • {sum[Vendas]/sum[Quantidade]} → Divide a soma de Vendas pela soma de Quantidade (Ticket Médio)
  • {mean[Idade]} → Média da coluna "Idade"
  • {count[Nome]} → Contagem de registros
  • {max[Valor]} → Valor máximo da coluna
  • {min[Valor]} → Valor mínimo da coluna

Importante: Os nomes das colunas devem ser escritos exatamente como estão no seu arquivo (case-sensitive).

Como calcular Ticket Médio ou outras métricas?

Use expressões matemáticas dentro das chaves! Exemplos práticos:

  • Ticket Médio: {sum[ValorTotal]/sum[QuantidadeItens]}
  • Percentual de conclusão: {sum[Concluidos]/(sum[Concluidos]+sum[Pendentes])*100}
  • Diferença entre valores: {sum[Receita]-sum[Custo]}
  • Média ponderada: {sum[Nota*Peso]/sum[Peso]}

Você pode usar qualquer operador matemático: +, -, *, /, ** (potência) e parênteses.

Dica: No corpo do e-mail, escreva algo como: "O valor total da campanha é R$ {sum[Valor]}" e o sistema substituirá pelo valor calculado.

Posso testar antes de enviar para todos?

Sim! Marque a opção "Sim" em "Deseja fazer um teste de envios de e-mail?". Assim, os e-mails serão enviados apenas para o seu próprio e-mail, permitindo verificar como a mensagem será exibida antes do envio definitivo.

Quais formatos de arquivo são suportados?

O sistema suporta arquivos nos formatos Excel (.xlsx, .xls) e CSV (.csv). Certifique-se de que a primeira linha do arquivo contenha os cabeçalhos das colunas.

Qual a diferença entre as opções de origem dos dados?

Anexar arquivo: Usa apenas o arquivo Excel/CSV enviado.
Usar DataFrame do arquivo: Gera uma tabela (dataframe) automaticamente a partir do arquivo e das colunas selecionadas.
Ambos: Utiliza tanto o arquivo original quanto o dataframe gerado.
Nenhum: Envia apenas o texto sem dados da planilha.

Os dados são salvos?

Sim! Todas as malas diretas enviadas são registradas no sistema e podem ser visualizadas na página "Histórico de Mala Direta", onde você pode consultar, testar novamente ou reenviar campanhas anteriores.

Dica: Como formatar números e moedas?

Os valores calculados serão exibidos no formato original. Para valores monetários, sugerimos escrever no corpo do e-mail:

R$ {sum[Valor]} → Exibe como "R$ 1234.56"
Total: {round(sum[Valor],2)} → Arredonda para 2 casas decimais

Ou simplesmente: "O valor total é R$ {sum[Valor]}" e o número aparecerá. Você também pode usar {int(sum[Valor])} para números inteiros.
