Dúvidas sobre Edição
Informações importantes para editar sua mala direta
Quem pode editar um registro?

Apenas o criador do registro pode editar. Se você não é o criador, a opção "Editar" não estará disponível para você. Nesse caso, você pode Duplicar o registro e editar a cópia.

Diferença entre os botões?
  • Salvar apenas: Atualiza o registro no banco de dados, mas não envia e-mails.
  • Salvar e Enviar: Atualiza o registro E envia os e-mails para os destinatários.
  • Enviar (não salvar): Envia os e-mails mas NÃO altera o registro salvo.
  • Sair: Volta para a lista sem fazer nenhuma alteração.
Como usar cálculos no corpo do e-mail?

Use expressões como:

  • {sum[Valor]} - Soma da coluna "Valor"
  • {mean[Idade]} - Média da coluna "Idade"
  • {count[Nome]} - Quantidade de registros
  • {sum[Vendas]/sum[Quantidade]} - Ticket médio
